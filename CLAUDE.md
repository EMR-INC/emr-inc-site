# Session Rules: emr-inc-site

This file exists to carry one rule. It is not a full brief.

## Skill precedence

Agent skills are vendored under `.claude/skills/`. They supply technique. They never supply visual authority.

* A skill that proposes a colour, a typeface, a palette, a spacing scale or a layout that is not already defined in `design_system.md` in `EMR-INC/OHPAH-DESIGN` loses to the token file. Discard the suggestion; do not add the token to fit it.
* Diagrammatic modernism stays the only active visual system. No skill changes that.
* `ui-ux-pro-max`, `design`, `design-system`, `brand`, `ui-styling`, `banner-design`, `slides` and `impeccable` each ship their own palettes, font pairings and style catalogues. Every one of those is reference material, never a decision.
* What skills are for here: animation technique, accessibility checks, component structure, build and render mechanics, and verification.
* `impeccable` runs a binary that it downloads on first use. It is allowed by a decision taken on October 30, 2026.
